GitHub 主页：https://github.com/qiuzxxxxx

启动
1. 电脑需安装 Python 3 和 Django。缺少 Django 时，在此文件夹运行 python -m pip install -r requirements.txt。
2. 双击 start.bat。首次启动会自动创建 SQLite 数据库。
3. 如果 Windows 防火墙弹出提示，允许 Python 在“专用网络”通信。
4. 在电脑浏览器打开 http://127.0.0.1:8765/。手机和电脑连到同一个 Wi-Fi 后，用手机相机扫页面上的二维码。
5. 手机可选文件上传到电脑；电脑也可把文件加入文件库，让手机预览或下载。文件保存在本文件夹的 received 目录，记录保存在 db.sqlite3。
6. 用完后回到黑色命令窗口按 Ctrl+C 关闭。

设备连接
- 手机扫码后自动连接，不需要输入安全码。
- 电脑页面会显示手机在线/离线状态，可断开已连接设备；设备状态保存在 SQLite。
- 二维码在服务运行期间持续有效，不必重启后立即扫码；点“刷新二维码”可在不重启服务的情况下更新连接地址。
- 二维码链接是连接凭证，请勿公开分享。手动刷新或重启服务后，旧二维码失效。
- “文件库”功能栏可查看收件列表；图片、视频、音频、PDF、DOCX Word 和 TXT/CSV/Markdown/JSON 文本支持预览。旧版 DOC 文件可下载后用 Word 打开。
- 文件库支持按名称搜索、排序和分页；最多选中 100 个文件打包为 ZIP 下载或批量删除，也可以重命名、替换、单个下载或删除。替换需保持原扩展名；删除会移除文件及其记录。
- 文件库会显示文件占用和磁盘可用空间。待发送队列保存在当前浏览器，刷新后可继续；失败文件可单独重试。
- “传输状态”统一显示手机到电脑、电脑到手机的当前进度；“传输记录”会保存已完成的文件传输及中断的下载。
- 电脑的连接状态在页面“设备连接”区域显示；离开页面一段时间后会自动显示离线。

如果手机和电脑不在同一个 Wi-Fi
- 如果它们仍在同一个可互通的家庭/办公网络里，通常可以直接使用。
- 也可以让电脑打开“移动热点”，让手机连接电脑热点；在电脑页面“连接网卡”选择热点对应的地址，再点“刷新二维码”。二维码会使用选定的电脑地址。
- 手机用蜂窝网络、电脑连家里的 Wi-Fi 这种互不相通的网络，不能直接连接电脑的局域网地址。
- 跨不同网络传输需要公网中转或额外的点对点连接服务；这个样品不使用云端。

样品限制
- 电脑需要安装 Python 3。
- 网页后端使用 Django；数据库使用 SQLite。
- 单次上传最多 250 MB，最多 40 个文件。
- 仅用于同一局域网内试用。上传文件保存在 received 文件夹；本样品不包含 EXE、数据库或云端服务。
