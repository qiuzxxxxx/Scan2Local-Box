# Scan2Local-Box

**本地收件箱**是一款运行在 Windows 电脑上的轻量文件传输工具。手机与电脑连接到同一个可互通的 Wi-Fi，或手机连接电脑开启的个人热点后，扫码即可传文件。文件保存在电脑本地，不经过云端中转。

## 开始使用

1. 安装 Python 3。
2. 在项目文件夹打开 PowerShell 或命令提示符，安装依赖：

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. 双击 `start.bat`。启动脚本会自动安装数据库迁移并启动 Django 服务。
4. 在电脑浏览器打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。如果 Windows 防火墙弹出提示，只允许 Python 通过可信的“专用网络”。
5. 手机连接同一个 Wi-Fi，扫描电脑页面上的二维码。使用个人热点时，让手机连接电脑热点；如果有多个网络地址，在电脑页面选择热点对应的网卡后刷新二维码。

## 双向传输

### 手机发送到电脑

手机扫码并连接后，选择照片或文件并发送。电脑页面会显示上传进度，文件保存到项目目录的 `received` 文件夹，也会出现在“文件库”中。

### 电脑发送到手机

在电脑页面选择文件并加入“文件库”。手机连接后打开“文件库”，即可预览或下载这些文件。文件下载时，电脑和手机页面都会显示传输进度。

### 管理与记录

“文件库”支持按名称搜索、按时间/名称/大小排序、分页浏览、预览、重命名和替换内容。最多可勾选 100 个文件打包下载为 ZIP，或批量删除；替换文件需保持原扩展名。页面也会显示文件库占用和磁盘可用空间。“传输记录”会列出手机上传到电脑、手机从电脑下载的记录。

单次最多传输 40 个文件，总大小不超过 250 MB。支持预览常见图片、PDF、DOCX、文本和音视频；其他格式可下载后打开。

待发送队列保存在当前浏览器本地，刷新页面后仍可继续；失败的文件可单独重试。文件传输完成后会自动从待发送队列移除。

## 网络和端口

电脑端服务使用 TCP 端口 `8765`。电脑浏览器通过 `127.0.0.1:8765` 访问本机页面；手机扫码使用二维码中的电脑局域网地址和同一个端口。

**端口号不是安全码，也不会包含或推导出安全码。** 端口只是访问本地网页服务的入口。二维码里另有一个运行时随机生成的连接凭证，用于首次连接设备；它不会写入本 README。请把二维码和完整连接链接当作凭证，不要公开分享。

服务通过 `0.0.0.0:8765` 接受本机网络连接，因此同一网络上的设备可以访问服务端口。实际传输仍需有效的二维码凭证或已配对设备密钥。此工具使用普通 HTTP，不提供传输加密，请只在可信的家庭或办公网络中使用，不要在路由器上配置公网端口转发。

电脑和手机必须处在彼此可以访问的网络中。两台设备都能上网，并不代表它们可以互相连接；例如手机只使用蜂窝网络、电脑只连接家中 Wi-Fi 时，不能直接传输。本工具不提供公网或云端中转。

## 二维码和设备连接

- 首次扫码时无需输入安全码；服务会验证二维码中的随机连接凭证，并为设备建立本地连接密钥。
- 点击“刷新二维码”会更换凭证，不需要重启服务；旧二维码不能再用于新设备配对，已配对设备仍可使用。
- 重启服务后会生成新的二维码凭证。需要重新配对或重新打开旧二维码页面时，请刷新电脑页面并扫描当前二维码。
- 设备和传输记录保存在本机 SQLite 数据库中。断开设备不会删除已保存的文件。

## 文件保存位置

- 接收文件：`received/`
- 文件、设备和传输记录：`db.sqlite3`

删除文件库中的文件会同时删除电脑磁盘上的对应文件。请自行备份需要保留的内容。

## 停止服务

回到运行 `start.bat` 的命令窗口，按 `Ctrl+C`。
