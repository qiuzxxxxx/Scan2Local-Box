# 本地收件箱

一个在 Windows 电脑上运行的轻量文件收发工具。手机和电脑连接到同一个 Wi-Fi，或手机连接电脑开启的热点后，扫码即可在两台设备之间传文件。文件直接保存在运行程序的电脑上，不经过云端。

## 开始使用

1. 安装 Python 3。
2. 在本文件夹打开命令提示符或 PowerShell，安装依赖：

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. 双击 `start.bat`。首次启动会自动初始化本地数据库。
4. 在电脑浏览器打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。如果 Windows 防火墙询问是否允许 Python 通信，请允许其在可信的专用网络中通信。
5. 手机连接同一个 Wi-Fi，用相机扫描页面上的二维码；也可以让电脑开启移动热点，再让手机连接该热点。

## 发送和接收文件

- **手机发送到电脑：** 手机扫码并连接后，选择照片或文件，点击“发送”。完成后，文件会出现在程序目录的 `received` 文件夹和页面的“文件库”中。
- **电脑发送给手机：** 在电脑页面选择文件并加入文件库。手机连接后，可在“文件库”中预览或下载这些文件。
- **管理文件：** 在“文件库”中可预览支持的文件、下载、重命名、替换内容或删除。替换文件时需保持原扩展名。
- **查看进度：** 页面会显示当前传输状态，并可在“传输记录”中查看记录。

单次最多发送 40 个文件，合计大小不超过 250 MB。图片、视频、音频、PDF、DOCX 和部分文本格式支持预览；其他格式可以下载后打开。

## 传送原理

电脑运行本地网页服务，手机扫码后访问二维码中的电脑局域网地址。选中文件后，手机浏览器通过局域网向电脑发送 HTTP 上传请求；电脑上的服务接收数据并写入 `received` 文件夹。下载时，文件则由电脑上的服务通过 HTTP 返回给手机。

二维码包含连接地址和随机连接凭证。首次连接时，电脑验证凭证并为手机创建设备密钥；之后的文件请求使用该设备密钥识别已连接设备。文件内容只在手机和电脑之间经当前网络传送，本程序不使用云端中转。电脑与手机必须处于彼此可访问的同一局域网；仅仅都能上网并不代表两者可以互相连接。

## 隐私与连接提示

- 二维码相当于连接凭证，请只分享给需要连接的设备。需要更换二维码时，在电脑页面点击“刷新二维码”；旧二维码将不能再用于新设备连接，已连接设备会保持连接。
- 服务重启后，旧二维码凭证失效；需要新设备连接时，请扫描当前页面上的二维码。
- 连接使用普通 HTTP，适合可信的家庭或办公局域网，不提供传输加密。避免在不可信的公共网络中使用，也不要公开分享二维码链接。
- 手机和电脑网络互不可达时（例如手机只用蜂窝网络，而电脑只连家庭 Wi-Fi），无法直接传送。本工具没有公网或云端中转功能。
- 关闭服务：回到启动 `start.bat` 的命令窗口，按 `Ctrl+C`。

## 文件保存位置

- 接收的文件：`received/`
- 文件、设备和传输记录等本地数据：`db.sqlite3`

请自行备份需要保留的文件。删除文件库中的文件会同时删除电脑上的对应文件。
